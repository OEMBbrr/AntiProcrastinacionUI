ESPECIFICACIONES TÉCNICAS Y ENTORNO DE DESARROLLO - ANTIPROCRASTINACIÓN

1. ANDROID NATIVO
- Lenguaje: Kotlin
- UI Framework: Jetpack Compose
- Package ID: com.antiprocrastinacion.lock
- Versión Actual: 13.0.0 (versionCode = 13, versionName = "13.0.0")
- Build System: Gradle con Kotlin DSL (archivos app/build.gradle.kts, build.gradle.kts, settings.gradle.kts)
- APKs de Salida: Se generan en la raíz del proyecto (AntiProcrastinacion_v13.apk)
- Min SDK: 26 (Android 8.0) | Target SDK: 35 (Android 15)

2. EXTENSIÓN DE GOOGLE CHROME
- Especificación: Manifest V3
- Arquitectura: JavaScript puro (Vanilla JS), HTML5, CSS3 (sin frameworks como React/Vue)
- Archivos clave: background.js, popup.js, popup.html, blocked.html, styles.css, manifest.json
- Paquete Web: pagina_web/downloads/extension_chrome.zip

3. BACKEND Y VINCULACIÓN DE DISPOSITIVOS (FIREBASE)
- Servicio Cloud: Firebase Realtime Database
- Endpoint RTDB Base: https://antiprocrastinacion-sync-default-rtdb.firebaseio.com
- Autenticación: Inicio de Sesión de 1 Clic con Google ("G Iniciar Sesión con Google") en Android y Chrome Extension
- Protocolo Apretón de Manos (Handshake 2-Way):
  * Estado por defecto: ROJO (Desvinculado) en ambos dispositivos
  * Android envía android_last_ping a /users/<google_key>/device_info.json
  * Chrome envía extension_last_ping a /users/<google_key>/device_info/extension_last_ping.json
  * Cambio a VERDE (Conectado): Solo cuando ambos detectan latido mutuo activo (< 30 segundos)

4. PLATAFORMAS ADICIONALES
- iOS: Flutter (lib/main.dart) con build automatizado en GitHub Actions (.github/workflows/build_apps.yml)
- Sitio Web: HTML5 / CSS3 / Vanilla JS (pagina_web/index.html) con descargas de APK v13 y Extensión ZIP

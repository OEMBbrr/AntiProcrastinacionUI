1. CONCEPTO Y FILOSOFÍA DE LA APLICACIÓN (VERSIÓN v17.0.0)
--------------------------------------------------------------------------------
"AntiProcrastinación" es un ecosistema multiplataforma (Android, iOS, Web y Extensión
de Google Chrome) diseñado para imponer autodisciplina real y eliminar la tentación
del desbloqueo impulsivo de dispositivos móviles y navegadores web.

A diferencia de otras apps que permiten saltar el bloqueo presionando un simple botón,
AntiProcrastinación utiliza un enfoque psicopedagógico de resistencia cognitiva:
- RETOS ANTI-PEGADO DE SEGURIDAD (ANTI-PASTE SECURITY):
  Se desactivó totalmente la función de copiar y pegar (onpaste/oncopy return false + detección de velocidad de tecleo).
  El usuario está OBLIGADO a teclear letra por letra el texto reflexivo de 150-200 palabras con ortografía,
  mayúsculas, acentos y signos de puntuación exactos.
- GESTOR DE ENLACES PERSONALIZADOS:
  Permite agregar, editar y eliminar dominios/sitios bloqueados personalizados (ej. tiktok.com, instagram.com).
- MODO CONTROL PARENTAL (+18 EXCLUSIVO EXTENSIÓN):
  Interruptor especial que bloquea exclusivamente la lista de sitios de contenido adulto e inapropiado
  (pornhub.com, xvideos.com, xnxx.com, xhamster.com, onlyfans.com, redtube.com, youporn.com, thumbzilla.com y sus variantes/TLD).
  IMPORTANTE: Las webs personalizadas SOLO se bloquean con el Modo Enfoque activo, NUNCA con solo el Control Parental.
- TREGUA TEMPORAL DE 5 MINUTOS:
  Para emergencias, exige resolver problemas matemáticos aleatorios o teclear frases medianas preparadas.
- INICIO DE SESIÓN OFICIAL GOOGLE (CHROME EXTENSION & ANDROID):
  Chrome Extension usa chrome.identity.launchWebAuthFlow() con el URI autorizado de Google Cloud Console:
  https://gecpnhjlelkcoiopicconbhkhdofigfi.chromiumapp.org/
  Ambas plataformas alinean las claves al nodo unificado /users/correo_sanitizado (ej. /users/oembbrr_gmail_com).
- ESTÉTICA WEB PRO ZEN:
  Diseñada con paleta Zen Verde Pizarra Pardo (#5A6E61), Gris Verdoso (#8C9B90), Carbón Oscuro (#2C302E), Crema (#F9F8F6) e iluminación neumórfica/glassmorphism.

2. COMPONENTE 1: APLICACIÓN NATIVA ANDROID (KOTLIN & JETPACK COMPOSE)
--------------------------------------------------------------------------------
Ubicación del código: C:\Users\USUARIO\Documents\AntiProcrastinacion\app\

- Paquete: com.antiprocrastinacion.lock (Versión Actual: 14.0.0 / versionCode = 14).
- Registro de APKs por Versión en la Raíz:
  Cada compilación genera el APK en la raíz con su versión correspondiente (AntiProcrastinacion_v14.apk, v13.apk, etc.) para seguimiento en Ajustes del teléfono.
- Monitoreo Hyper-Responsivo (LockMonitoringService.kt):
  Servicio en primer plano que verifica el estado cada 80ms y superpone ZenScreen al detectar lanzadores o apps no autorizadas.
- Inicio de Sesión con Google Nativo (Credential Manager + Firebase Auth):
  Utiliza el SDK androidx.credentials con Credential Manager para inicio de sesión en 1 clic con Google, obteniendo un ID Token e iniciando sesión en Firebase Auth (`signInWithCredential`).
- Apretón de Manos Bidireccional Estricto (Handshake 2-Way Rojo/Verde en Tiempo Real):
  * Punto de estado inicial: ROJO (🔴).
  * Usa Firebase Realtime Database SDK autenticado para escribir en `/users/<UID>/device_info/android_last_ping`.
  * Escucha en tiempo real vía `ValueEventListener` en `/users/<UID>/device_info/extension_last_ping`.
  * Cambia a VERDE (🟢) únicamente cuando detecta un latido activo de la Extensión (< 30 segundos).

--------------------------------------------------------------------------------
Ubicación del código: C:\Users\USUARIO\Documents\AntiProcrastinacion\extension_chrome\

- Inicio de Sesión con Google & Autenticación REST:
  * Autenticación nativa con `chrome.identity.launchWebAuthFlow()` e integración directa con Firebase Auth REST API (`accounts:signInWithIdp`).
  * Badge inicial: 🔴 Desvinculado.
  * Envía latidos autenticados a `/users/<UID>/device_info/extension_last_ping` y lee `android_last_ping`.
  * Al detectar el latido del teléfono en tiempo real, activa el badge verde: 🟢 Conectado: TECNO POVA 6.
- Selector de Tiempo Doble Horas y Minutos:
  * Controles stepper separados de HORAS (00-23) y MINUTOS (00-59) de 1 en 1 minuto.
- Bloqueo Separado (Enfoque vs Parental):
  * Modo Enfoque: Bloquea exclusivamente sitios personalizados agregados por el usuario.
  * Control Parental: Bloquea exclusivamente contenido adulto (+18).
  * Filtros comodín (*<keyword>*) en declarativeNetRequest, chrome.webNavigation.onBeforeNavigate y chrome.tabs.onUpdated.
